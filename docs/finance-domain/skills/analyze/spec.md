# 财报指标解析 · 计划契约

计划阶段产出一份取数清单（过 `schemas/plan.schema.json` 校验）。清单只列「要取哪些事实键」，不含任何数值——数值只能由执行阶段从图谱取回并经 save_fact 落盘。

## 事实键清单（ROA / ROAE，招商银行口径示例）

| key | 含义 | 期间 |
|---|---|---|
| ni_attr | 归属于本行股东的净利润 | 当年 |
| assets_end / assets_beg | 资产总额 | 年末 / 年初 |
| eq_end / eq_beg | 归母权益总额 | 年末 / 年初 |
| other_eq_end / other_eq_beg | 其他权益工具（优先股+永续债） | 年末 / 年初 |
| div_pref | 当年优先股股息 | 当年 |
| int_perp | 当年永续债利息 | 当年 |

## 逐项口径（写死，不许互相套用）

- **ROA** = 归母净利润 ÷ 平均资产总额。分子不扣优先股股息与永续债利息（归母净利润已在报表层处理），只用资产端平均。
- **ROAE** = （归母净利润 − 优先股股息 − 永续债利息）÷ 平均普通股股东权益，其中平均普通股股东权益 = 平均归母权益 − 平均其他权益工具。
- 每新增一个指标，必须在本文件新增一节逐项口径；禁止写「按普通股口径调整」这类总则句——实测总则会被模型过度推广到不该扣的指标上。

## 执行纪律

1. 取数只认图谱原文，查不到的键如实报缺，不许估、不许用相邻口径的数顶替（净利润总数 ≠ 归母净利润）。
2. 每个事实落盘必须带出处（章节/附注/页码），无出处不落盘。
3. 计算与对账全部由执行器代码完成；对账不过时，模型只能按失败分类回图谱重取对应键，不许改公式、不许改判。
4. 重试上限 3 次；仍不过，升级给图外维修（见 review.md），维修结论回来后必须重新走一遍取数→计算→对账，不许直接采信维修方给的数。
