# Autonomous Delivery Proof（中文阅读版）

> 本文件为 `SKILL.md` 的中文阅读版，方便人类阅读与评审；Agent 实际执行的规范以同目录 `SKILL.md` 为准。

## 核心原则

仅在用户**明确授权**全自动或过夜交付（如 `/goal`）且方案已敲定时启用：在独立 Git Worktree 中一气呵成完成实现、UI 与克制微动效打磨、全量验证、PR 合并，并在 `~/Downloads/` 生成可直接双击打开运行的离线 HTML 验收证明。

## 执行步骤

1. **Git Worktree 隔离开发**：在独立分支/Worktree 推进，保持提交干净、零密钥泄露。
2. **功能落地 + 专业质感打磨**：先完成核心功能，再精修视觉层级、克制且尊重 `prefers-reduced-motion` 的微动效与性能。
3. **全量门禁跑通不停手**：自动跑通 typecheck / lint / unit / build / E2E 与真实端到端实测，遇到失败自主定位修复直至全绿。
4. **生成 `~/Downloads/` 可运行 HTML 验收报告**：离线内嵌真实截图（Base64）、原始验证日志、线上版本/PR 链接，并附可直接交互验证的演示区。
5. **干净交付**：提交、推送、创建/合并 PR，确认工作区干净后汇总汇报。

## 反模式

- ❌ 用户只是在讨论或 Code Review 时擅自进入全自动改代码/合并 PR 模式。
- ❌ 验收报告里伪造数据、引用打不开的本地图片路径或跳过验证门禁。
