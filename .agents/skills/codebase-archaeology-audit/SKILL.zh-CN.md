# Codebase Archaeology Audit（中文阅读版）

> 本文件为 `SKILL.md` 的中文阅读版，方便人类阅读与评审；Agent 实际执行的规范以同目录 `SKILL.md` 为准。

## 核心原则

对代码库做深度体检与工程沉淀：从 Git 历史里剥离不再需要的历史包袱，以“明天刚入职的高水平工程师”视角审计认知成本，并把反复出现的 Bug 与返工沉淀为规则、自动化守卫测试或 Skill。

## 执行步骤

1. **Git 历史与架构包袱考古**：梳理关键提交与 PR 演变，区分「有意设计」与「为已消失问题引入的历史遗留」，列出可安全移除的包袱清单。
2. **新人接手认知成本审计**：找出命名混乱、抽象过度、职责不清、强依赖隐性上下文的模块，给出精确到文件和符号的简化方案。
3. **Bug 与返工根因复盘**：复盘指定时间窗口内的 Bug、回滚和重复修改，不只统计数量，必须抽象出共同根因。
4. **沉淀防复发护栏**：把共性根因转化为项目规则（`CLAUDE.md`/`AGENTS.md`）、自动化守卫测试或专属 Skill，避免重复付费。
5. **验证落地**：任何清理或新增守卫均需跑通全量验证门禁。

## 反模式

- ❌ 只罗列现象不挖共同根因，或只给空泛的重构建议。
- ❌ 复盘只停留在文字总结，没有沉淀为规则、自动化测试或 Skill。
