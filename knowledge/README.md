# 活动知识库总览

这是知识库的入口，接到任何搭建需求都先读这一篇。

## 怎么用

1. 先在下表里确定活动类型，进入对应目录。
2. 读该目录下的 `campaign.md`（L1），拿到覆盖国家、档期引用规则和页面清单。
3. 页面清单里每种页面对应一个 `pages/*.md`（L2），读它拿到完整楼层结构。
4. 楼层表里的 `scheduling_type` 决定下一步动作，不要自己猜。

不要硬编码文件路径以外的任何 ID；需要什么就按目录往下找。

## 活动类型

| 类型 | 说明 | 目录 |
|---|---|---|
| 大促 | 多国家、多会场的大型促销，如 618、双 11、黑五 | `mega-sale/` |
| 品牌日 | 单品牌、单页面的品牌活动 | `brand-day/` |

## 共享知识

| 文件 | 内容 | 消费者 |
|---|---|---|
| `shared/components.md` | 组件字典：组件名、用途、限制 | 规划 |
| `shared/review-rules.md` | 搭建结果验收规则 | 审查 |
